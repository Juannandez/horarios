# Horarios SAT · versión de demostración

Copia estática de la app de cuadrantes (sin servidor) publicada con GitHub Pages. Funciona entera en el navegador:
genera el cuadrante con los valores de partida, y lo que cambies se guarda solo en ese navegador. Para trabajar con
una configuración propia, impórtala en **Ajustes → Datos → Importar configuración**.

No contiene datos personales: las personas son anónimas (TA 001, SUP 01…).
